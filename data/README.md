# Demo dataset

The 12 original procedurally generated MIDI melodies are generated by running:

```bash
python demo_data.py
```

This script creates `data/original_demo_0.mid` through `data/original_demo_11.mid`. The original MIDI binaries are also included in the downloadable SonataAI project archive supplied in the chat. For real genre training, add appropriately licensed classical/jazz MIDI files to this folder.
